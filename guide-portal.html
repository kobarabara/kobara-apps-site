ENSEMBLE PORTAL GUIDE

オーケストラ・アンサンブルの団体運営アプリ「Ensemble Portal」使い方ガイド

Ensemble Portalは、音楽団体の公開ページと、団員向けの連絡・予定・楽譜・動画をひとつにまとめるサービスです。このガイドでは、団体を作る方と参加する方が、最初に何をすればよいかを順番に説明します。

OVERVIEW

1. Ensemble Portalでできること

情報をすべて公開する必要はありません。外部の方に見せる情報と、団員だけに見せる情報を分けて管理できます。

公開団体ページ

団体紹介、募集情報、公開したい動画などを掲載し、参加希望者の窓口にできます。

団員向けポータル

お知らせ、練習予定、出欠、楽譜、動画、イベント調整を、ログインした団員だけに共有できます。

活動の準備

練習日程と場所を整理し、出欠を集め、必要な楽譜や連絡を同じ場所に置けます。

演奏会・行事の調整

候補日と会場候補を比較し、決まった日時と場所を団員へ共有できます。

はじめから全機能を使う必要はありません。まずは「団体紹介」「団員招待」「最初の練習予定」の3つだけで始められます。

FOR ORGANIZERS

2. 団体を作る方：最初の30分

団体を作る方は、最初に運営者アカウントでログインします。アカウントがない場合は、団体作成の途中で新規登録へ進めます。

  1. 団体名を決めて、団体を作成します。
    まずは普段使っている正式名称で登録してください。
  2. 公開ページの基本情報を入力します。
    団体の紹介文、募集状況、練習場所・頻度など、初めて知る人が判断する情報から整えます。
  3. 最初の練習予定を登録します。
    日時、場所、必要なら曲目を入力します。ここで団員が出欠登録できるようになります。
  4. 団員を招待します。
    最初は役員・パートリーダーから招待すると進めやすくなります。
最初に公開しなくても大丈夫ですか？
大丈夫です。公開ページの掲載・参加申請の受付は、団体の準備が整ってから始められます。団員向けの運営を先に始めることもできます。

FOR MEMBERS

3. 団員として参加する方

団体への参加方法は、団体の運用により異なります。案内された方法を使ってください。

公開ページから参加申請する場合

  1. 参加したい団体の公開ページを開きます。
  2. 参加申請の案内から、必要事項を入力して送信します。
  3. 団体側の確認・承認後、案内に沿ってアカウント登録またはログインします。

団体から招待された場合

団体管理者から届いた案内に従ってください。すでに別の団体でEnsemble Portalを使っている場合でも、確認を経てから新しい団体に参加します。

参加できない、または「すでに登録されています」と表示される場合は、新しいアカウントを作り直さず、団体管理者へ状況を連絡してください。

DAILY ACTIVITY

4. 日々の活動を管理する

お知らせ

後から見返す必要がある決定事項・変更・資料案内を掲載します。

練習予定を追加する

練習予定を編集できる権限を持つ方が、団員へ日時・場所・曲目を共有するための手順です。

  1. メニューから「練習予定」を開きます。
    一覧の右上にある「＋ 練習予定を追加」を選びます。
  2. 日付・開始時刻・終了時刻・場所を入力します。
    登録済みの会場がある場合は選択できます。会場を選ばない場合は、場所名を直接入力します。
  3. 必要な楽譜を選びます。
    一覧から曲を選ぶか、未登録の曲は補足欄に曲名や編成を入力します。
  4. 「追加」を押します。
    一覧に戻り、日時・場所・選択した曲が正しいか確認します。

出欠を登録・変更する

団員は練習予定の詳細から出欠を登録します。予定が変わった場合は、同じ画面で内容を更新してください。

練習場所を繰り返し使う場合

よく使う会場は「会場を管理」で登録しておくと、次回から選択するだけで名称・住所を使えます。部屋名や集合場所だけを変えたい場合は、練習予定の場所欄に補足します。

SCORES

5. 楽譜を管理する

楽譜を編集できる権限を持つ方が、曲名ごとに必要なパート譜を登録する手順です。団員は登録済みのパート譜を一覧から確認・ダウンロードできます。

  1. メニューから「楽譜一覧」を開きます。
    「楽譜アップロード」を選びます。
  2. 曲名を入力します。
    同じ曲を複数回登録しないよう、登録済みの一覧を先に確認してください。
  3. パート名とファイルを登録します。
    必要なパートごとにPDFなどのファイルを選び、表示順を決めます。最初は最大5件までまとめて登録できます。
  4. 「アップロード」を押します。
    楽譜一覧に戻り、曲名・パート名・ダウンロードできるファイルが正しいか確認します。
差し替えや追加をした場合は、必要に応じて「楽譜のアップロード通知」またはお知らせで団員へ知らせてください。不要になったファイルや曲を削除する前には、過去の練習や団内の運用に影響しないか確認してください。

SURVEYS

6. アンケートを作成・公開する

アンケートは、作成者または共同編集者が下書きを作り、質問・回答対象を確認してから公開します。回答対象は、団体全員・ロール・パート・個別指定から選べます。

  1. メニューの「その他」から「アンケート」を開きます。
    「＋ アンケートを作成」を選び、題名・説明・匿名設定・締切などを入力して「下書きを作成して質問を追加」を押します。
  2. 質問を追加します。
    「＋ 質問を追加」から回答形式を選び、質問文と必要な選択肢を入力します。質問の並び順も確認します。
  3. 「回答画面をプレビュー」で確認します。
    回答者に見える選択肢や日付入力を試せます。このプレビューで入力しても回答は保存されません。
  4. 「回答対象を設定」で対象者を保存します。
    対象人数と、誰に依頼するかを確認します。
  5. 「公開してメールを送信」を押します。
    公開後は質問と回答対象を変更できません。公開前に題名・設問・対象者・締切を確認してください。
公開済み・受付終了済みのアンケートも削除できますが、質問・回答・集計結果も同時に削除され、元に戻せません。削除する前に必要な結果を確認してください。

VIDEOS

7. 演奏会・レッスン動画を整理する

動画は、外部サービスにアップロード済みの動画URLを登録して、団体内で見やすく整理するための機能です。

  1. 動画一覧から動画を追加します。
    タイトル、説明、動画URLを入力します。
  2. カテゴリを選びます。
    「演奏会」「レッスン」など、団体で必要なカテゴリを作っておくと、あとから探しやすくなります。
  3. 表示先を選びます。
    団員向けだけに表示する動画と、公開団体ページにも掲載する動画を使い分けます。
公開ページに掲載する動画は、出演者・撮影者・著作権者との取り決めを確認してから設定してください。

EVENT PLANNING

8. 演奏会や行事の日程を調整する

演奏会、合宿、打ち上げなど、通常練習とは別に決めたい予定はイベント調整で管理します。

  1. イベントを作成します。
    イベント名と候補日を登録します。時間が未定なら、日付だけで候補を作ることもできます。
  2. 必要に応じて会場候補を追加します。
    候補日ごとに会場候補や補足を登録し、比較できるようにします。
  3. 団員の回答を確認します。
    候補日ごとの状況を見て、日程と会場を決めます。
  4. 確定します。
    確定した日時・会場・住所はイベント一覧で共有されます。

PUBLIC PAGE

9. 団体の公開ページを整える

公開ページは、参加希望者や演奏会を知った方が団体を最初に知る場所です。団員しか見る必要がない情報は公開せず、団員ページに置きます。

掲載するとよい情報

団体紹介、活動地域、練習頻度、募集状況、募集しているパート、参加希望者への案内。

公開を慎重にする情報

団員の連絡先、詳細な出欠、限定配布の楽譜、公開許可のない写真・動画、会場の入室方法など。

参加申請を受け付ける

団体が新規参加者を受け入れる場合は、公開ページから参加申請を受け付けられます。募集停止中は、受付を止めた状態にできます。

SAFE MANAGEMENT

10. 団体を安全に運営する

役割に応じて編集権限を分ける

すべての管理を一人で抱え込む必要はありません。運営者は、予定・楽譜・お知らせなどを担当者へ分け、必要な範囲だけ編集できるようにします。

退団・休団時の扱い

活動に参加しない方は、団体の運用に合わせて利用状態を見直します。別の団体へ参加する場合も、本人の確認なしに団体へ追加されることはありません。

メールが届かない場合

迷惑メールフォルダ、受信拒否設定、登録したメールアドレスを確認してください。解決しない場合は、団体管理者に連絡し、どの画面で何が起きたかを伝えてください。

パスワードを忘れた場合
ログイン画面のパスワード変更・再設定の案内を利用してください。ログインできない状態で新しいアカウントを作る前に、登録済みメールアドレスで再設定できるか確認します。
